# Editor support

- [Dodo for VS Code](dodo-vscode): a VS Code extension with LSP integration,
  syntax highlighting, language configuration, and snippets.
- [Dodo for Zed](dodo-zed): a Zed extension with LSP integration, Tree-sitter syntax
  highlighting, bracket pairing, indentation, outlines, and Vim text objects.

Other editors can connect their LSP client to `dodo lsp` over standard input/output.
See the [editor setup guide](https://jotrorox.github.io/dodo/editors/).
